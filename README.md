# 📊 WorkTrack

Helps freelancers track projects, log hours, and monitor progress in one clean workspace. Stay organized, move faster, and make better decisions with clear stats and insights.

![An animated gif showing the project dashboard in action.](./public/landing.gif)

## 📈 Features
- **Time tracking:** Log hours of work in seconds.
- **Project control:** Stay on top of every task all the time.
- **Clear insights:** See where all your time goes.
- **Customizable:** Customize everything, work yor way.
